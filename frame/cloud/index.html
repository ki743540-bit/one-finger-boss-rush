Frameをはじめよう。

実際の動画取得は、PCで動くFrameエンジンが行います。

  1. PCで下のZIPをダウンロードして展開。
  2. Python 3.11以降・FFmpeg・Node.jsを準備。詳しくは同梱の「README」を確認。
  3. Windowsは「start.bat」をダブルクリック。
  4. 開いた画面にリンクを貼って保存。
